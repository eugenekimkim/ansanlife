# 출시 전 확인 · 신청 목록

개발과 별개로 사람이 확인하거나 신청해야 하는 일입니다. 확인한 값은 `docs/HANDOFF.md` 의 "확인된 정보와 출처" 표와 앱 코드에 함께 반영하세요.

## 안산시 자원순환과 (031-481-2259) 문의

1. 일반·음식물 쓰레기 **일요일 배출** 가능 여부 (공공데이터끼리 충돌. 앱은 지금 "일–금")
2. 재활용품 배출 요일이 시 전체 **월·화·목·금**이 맞는지, 동별로 다른지
3. 배출 시간 **20:00–다음 날 06:00** 이 맞는지
4. **투명 페트병** 별도 배출 요일·방법
5. 깨끗한 흰 스티로폼, 깨진 유리, 계란 껍데기·뼈·티백 등 헷갈리는 품목 분류 확인 (앱 `items8`, 서버 `RULES`)
6. 폐건전지·형광등 수거함 위치 안내 방법
7. **대형폐기물 수수료** 표와 신청 링크 (앱은 "월·목 수거, 1666-1234")
8. 외국어(베트남어 등) 배출 안내 자료가 있으면 원본 받기
9. 앱에 시 로고·자료를 써도 되는지, 협업 방식

## 광고 영업

- 광고 상품 정하기: 위치(홈·공지 화면), 언어(국적) 타깃, 기간, 단가
- 후보: 해외송금, 알뜰폰·통신, 원곡동·초지동 지역 상점, 외국인 대상 병원·학원
- 계약한 광고는 Supabase `ads` 에 등록 (문구는 그 언어로, 제목 80자·설명 160자 이내)
