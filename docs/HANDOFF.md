## 한눈에 보기

안산살이(Ansan Life)는 안산 거주 외국인 주민을 위한 다국어 생활 안내 모바일 서비스이고, 지금은 **디자인 시안(Figma)과 눌러볼 수 있는 모바일웹 프로토타입**까지 완성된 상태입니다. 실제 데이터 연결과 카메라·위치 기능은 아직입니다.

- **대상:** 안산(반월·시화공단, 원곡동·초지동 등) 거주 외국인 근로자와 가족
- **핵심 기능:** 분리배출, 버스·교통, 관공서, 병원·약국, 공지·행사, 설문
- **수익 모델:** 앱 내 광고(국적별 타깃 광고 · 송금, 통신, 지역 상점) + 지자체 협업. 설문은 추후 외국인 대상 리서치 패널로 확장 가능
- **설문 보상:** 설문을 끝까지 마치면 **24시간 광고 제거**
- **언어:** 한국어 · 영어 · 베트남어 운영 / 중국어 · 러시아어 · 우즈베크어 · 몽골어는 "준비 중"
- **배경:** 안산시 정부사업 수행 중. 급여·노동법 영역(어서와, 오퍼센트ai)은 이 서비스 범위에서 제외

## 주의할 점

- 화면의 [대괄호]와 Sample 표시는 빈자리입니다. 추측한 값으로 채우지 말고 출처를 확인해 넣으세요.
- 카메라 실시간 화면, GPS, 외부 지도는 HTTPS 도메인에 올린 버전에서만 시험할 수 있습니다(개발 중에는 `http://localhost` 도 됨).
- 사진 분석 결과의 품목명은 AI가 쓰지만, 배출 분류·요일·봉투는 앱의 안산시 기준으로만 보여줍니다. 분류표를 고치면 `server/worker.js` 의 `RULES` 와 앱의 `DEST` 를 함께 고치세요.
- 수정은 `src/app.template.html` 에서 하고 `python3 build.py` 로 `index.html` 을 다시 만드세요.

- 출시 전 사람이 할 일(안산시 문의, API 신청, 번역 검수, 법률 검토)은 `docs/CHECKLIST.md` 에 모아 두었습니다.
- 공지는 한국어로만 넣으세요(Supabase `notices`, 또는 임시로 `data/notices.json`). 번역은 서버가 하고, 내용이 바뀌면 다시 번역합니다.
- Supabase `service_role` 키는 앱·저장소·Worker 어디에도 넣지 마세요. 앱에는 anon(공개) 키만 들어갑니다.
- 앱 형태는 2026-10-27 결정대로 웹앱(PWA) 먼저. 스토어 앱은 필요할 때 같은 코드를 감싸서(Capacitor 등) 진행
