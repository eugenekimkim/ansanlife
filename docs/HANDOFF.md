## 한눈에 보기

안산살이(Ansan Life)는 안산 거주 외국인 주민을 위한 다국어 생활 안내 모바일 서비스이고, 지금은 **디자인 시안(Figma)과 눌러볼 수 있는 모바일웹 프로토타입**까지 완성된 상태입니다. 실제 데이터 연결과 카메라·위치 기능은 아직입니다.

- **대상:** 안산(반월·시화공단, 원곡동·초지동 등) 거주 외국인 근로자와 가족
- **핵심 기능:** 분리배출, 버스·교통, 관공서, 병원·약국, 공지·행사, 설문
- **수익 모델:** 앱 내 광고(국적별 타깃 광고 · 송금, 통신, 지역 상점) + 지자체 협업. 설문은 추후 외국인 대상 리서치 패널로 확장 가능
- **설문 보상:** 설문을 끝까지 마치면 **24시간 광고 제거**
- **언어:** 한국어 · 영어 · 베트남어 운영 / 중국어 · 러시아어 · 우즈베크어 · 몽골어는 "준비 중"
- **배경:** 안산시 정부사업 수행 중. 급여·노동법 영역(어서와, 오퍼센트ai)은 이 서비스 범위에서 제외

## 디자인 규칙

오프화이트 바탕 + 세리프 제목 + 세이지 톤 + 크게 휘어진 모서리. 사무적이지 않고 그래픽적인 느낌 유지.

| 항목 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 강조색 (accent) | #E45C4E | 아이콘 버튼, 선택 표시, 점, 밑줄, 진행 바. 흰 글씨 배경 버튼에는 쓰지 않음(대비 약 3.6:1) |
| 딥그린 (deep) | #22393A | 글자가 든 큰 버튼, 티켓 카드, 제목 |
| 배경 (background) | #F3F2EF | 화면 바탕, 연한 카드 |
| 세이지 (sage) | #8FA7AC | 하단 푸터 띠 |
| 글자 / 보조 | #1E2221 / #6E7472 | 본문 / 설명 |
| 제목 글꼴 | Playfair Display(영·베) / Noto Serif KR(한) | |
| 본문 글꼴 | Quicksand(영·베) / Noto Sans KR(한) | |

- 화면 구조: "Menu ───" 줄 → 세리프 제목 → 왼쪽 위 48px 곡선 흰 시트 → 세이지 푸터
- 인트로: 주황/하늘색 배경 약 5.5초 크로스페이드, 제목 위 선·아이콘 없음, "어디에서 오셨나요? / Where are you from?"
- 국가 카드: 132×116, 라운드 20, 국기 원형 32px·테두리에서 14px, 번호 없음, 선택 시 140×128 흰색 + 체크
- CSS-Tricks식 겹친 카드, 드래그 스크롤, 호버·터치 시 떠오름
- 준비 중 언어 선택 시 아래 흰 영역에만 "준비 중입니다 · Coming soon", 다음 버튼 비활성
- 모든 버튼·카드에 눌림 효과, 외국어 화면에도 한국어 보조 문구 병기, 이모지·네이버 로고 사용 안 함
