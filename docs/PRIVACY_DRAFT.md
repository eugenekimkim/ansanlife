# 개인정보 처리 · 동의 문구 초안 (법률 검토용)

> 이 문서는 **변호사·개인정보 전문가 검토용 초안**입니다. 앱이 실제로 처리하는 정보를 코드 기준으로 정리하고, 화면 문구 초안을 붙였습니다. 법적 판단(신고 필요 여부, 국외 이전 고지 방식 등)은 검토 결과에 따라 고쳐 주세요.
> 작성 2026-10-26 · 기준 코드: `feature/camera-gps` 브랜치

## 1. 앱이 처리하는 정보 (코드 기준)

| 기능 | 처리하는 정보 | 어디로 가나 | 저장 | 비고 |
| --- | --- | --- | --- | --- |
| 사진으로 물어보기 | 사용자가 찍은 사진(긴 변 1024px JPEG), 화면 언어 | 우리 API 서버(Cloudflare Workers) → Anthropic(Claude API, 미국) | 우리 서버는 저장·기록하지 않음. Anthropic의 API 데이터 보관 정책은 별도 확인 | **국외 이전**에 해당할 수 있음 |
| 지역 변경 · 현재 위치 | 기기 위치 좌표(위도·경도) | 네이버 클라우드 Maps(Reverse Geocoding) | 좌표·주소는 사용자 기기(localStorage)에만 | 위치정보법상 의무 확인 필요 |
| 지역 변경 · 주소 입력 | 입력한 주소 문자열 | 네이버 클라우드 Maps(Geocoding) | 사용자 기기에만 | |
| 주변 정류장 | 집 주소 좌표(소수점 6자리) | 우리 API 서버 → 공공데이터포털(경기도 버스 API) | 서버 저장 안 함(15초~5분 캐시) | 좌표가 서버를 거쳐 감 |
| 공지 번역 | 공지 원문(우리가 올린 것) | 우리 API 서버 → Anthropic | 번역 결과를 서버 캐시에 하루 | 개인정보 아님 |
| 설문 | 선택한 답(코드), 화면 언어 | Supabase(서울 리전 권장) | 서버에 저장. 이름·연락처·기기 식별자 없음 | 2026-10-27부터 서버 저장. 동의·보유 기간 정해야 함 |
| 광고 | 화면 언어(광고 고르기) | Supabase (직접 광고 조회) | 저장 안 함 | 언어=국적 추정으로 타깃 |
| 광고 네트워크(설정 시) | 쿠키, 기기·접속 정보 | Google AdSense | Google 정책 | 쿠키 고지·동의 필요 여부 확인 |
| 광고 제거 · 설정 | 광고 제거 만료 시각, 언어, 배출 요일, 네이버지도 열기 방식 | 기기에만 | 기기 | |
| 기타 | 접속 로그(IP 등) | GitHub Pages, Cloudflare(호스팅사 기본 로그) | 각 사 정책 | 처리위탁 고지 대상인지 확인 |

계정·이름·전화번호는 현재 수집하지 않습니다. 회원 기능을 붙이면 이 표를 다시 써야 합니다.

## 2. 검토가 필요한 쟁점

1. **사진의 국외 이전(Anthropic, 미국)**: 개인정보보호법상 국외 이전 고지·동의 방식. 사진에 얼굴·문서가 찍힐 수 있음.
2. **위치정보**: 기기 좌표를 네이버로 보내 주소로 바꾸는 구조에서 위치정보법상 신고·약관·동의가 필요한지.
3. **처리위탁 고지**: Cloudflare, Anthropic, NAVER Cloud, Supabase, GitHub(호스팅), (설정 시) Google AdSense 표기 방식.
4. **설문 보상(24시간 광고 제거)**: 경품·보상 관련 고지 필요 여부, 설문을 리서치 패널로 확장할 때의 별도 동의.
5. **국적별 타깃 광고**: 국적(선택한 언어)을 광고에 쓰는 것이 민감정보·프로파일링 고지 대상인지.
6. **아동**: 가족 단위 이용 시 만 14세 미만 이용 가능성.
7. **모국어 고지**: 7개 언어로 같은 효력의 문구를 제공하는 방식(한국어 원문 우선 조항 등).

### 사진 분석 첫 사용 시 동의 (초안)

> **사진으로 물어보기**
> 찍은 사진을 AI가 분석해 어떻게 버리는지 알려드려요.
> - 보내는 정보: 찍은 사진 1장
> - 받는 곳: 안산살이 서버 → Anthropic(미국, AI 분석)
> - 보관: 분석이 끝나면 저장하지 않아요
> - 사람 얼굴이나 서류가 찍히지 않게 물건만 찍어 주세요.
> [동의하고 시작] [사진 없이 품목 검색]

### 현재 위치 사용 동의 (초안)

> **현재 위치로 동네 찾기**

> - 보내는 정보: 현재 위치 좌표
> - 받는 곳: NAVER Cloud(주소 변환)
> - 보관: 찾은 주소는 이 휴대폰에만 저장돼요
